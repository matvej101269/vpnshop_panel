Адрес панели VPN Shop

Публичный адрес используется для webhook Lava.top и ссылок. Для доступа по домену также настройте DNS и HTTPS reverse proxy на сервере.

Например, для localhost:8000 и пути admin адрес будет http://localhost:8000/admin.
{{config.panel_scheme}}://{{config.panel_domain}}:{{config.panel_port}}/{{config.panel_uri_path.strip('/') or 'admin'}}
