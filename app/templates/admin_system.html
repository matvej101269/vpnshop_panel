Управление сервисом

Обновление загружает main из origin, собирает новый образ и пересоздаёт приложение.

{% if not control_enabled %}

Для управления Docker нужен внутренний сервис control. Новая установка создаёт его автоматически. Для существующего VPS добавьте случайный токен в .env и пересоздайте сервисы:

cd /opt/vpnshop
echo "CONTROL_TOKEN=$(openssl rand -hex 32)" >> .env
git pull
docker compose up -d --build
