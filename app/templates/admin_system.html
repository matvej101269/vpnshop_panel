Управление сервисом

Обновление загружает main из origin, собирает новый образ и пересоздаёт приложение.

{% if not control_enabled %}

Для управления Docker нужен внутренний сервис control. Новая установка создаёт его автоматически. Для существующего VPS добавьте случайный токен в .env и пересоздайте сервисы:

cd /opt/vpnshop
echo "CONTROL_TOKEN=$(openssl rand -hex 32)" >> .env
git pull
docker compose up -d --build
{% endif %}

{% if not backup_key_configured %}

Не задан BACKUP_ENCRYPTION_KEY. Добавьте в .env VPS ключ командой echo "BACKUP_ENCRYPTION_KEY=$(openssl rand -base64 32 | tr '+/' '-_')" >> .env и пересоздайте контейнер: docker compose up -d. Сохраните этот ключ отдельно: без него копии не расшифровать.
