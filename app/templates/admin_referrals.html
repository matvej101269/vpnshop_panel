Реферальная программа

Приглашённый закрепляется за первым пригласившим при первом запуске бота по его ссылке. Привязка бессрочная. Дни начисляются после каждой успешной оплаты выбранного тарифа.

{% for plan in referral_plans %}{% else %}{% endfor %}

{{plan.name}} · {{plan.amount}} {{plan.currency}}0 — не начислять
Сначала создайте тариф.

Начисленные дни продлевают текущую подписку пригласившего. Если у него ещё нет подписки, создаётся доступ на число бонусных дней с параметрами оплаченного тарифа. Бот хранит только Telegram ID для бессрочной привязки.
