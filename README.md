# VPN Shop — Telegram, Lava.top и 3x-ui

Приложение автоматизирует продажу VPN-подписок: Telegram-бот, веб-панель, база SQLite, оплата через Lava.top, создание клиента в 3x-ui и ссылка подписки для Happ. Целевой сервер — Ubuntu 22.04; локально можно разрабатывать и запускать на Windows.

## Запуск для разработки

1. Установите Python 3.12+ или Docker Desktop.
2. Скопируйте `.env.example` в `.env` и задайте `ADMIN_USER` и длинный `ADMIN_PASSWORD` для первого входа.
3. Запустите `pip install -r requirements.txt`, затем `python -m app` (или `docker compose up --build`).
4. Откройте `http://localhost:8000/admin` и войдите с начальными данными.
5. В разделе «Настройки» заполните интеграции, сохраните конфигурацию и заведите тарифы в разделе «Подписки».

На первом запуске `.env` используется только для пути к базе и создания администратора. Токен бота, параметры Lava.top, параметры 3x-ui, адрес Happ и остальные рабочие настройки после инициализации управляются через админку. Значения секретов шифруются в БД ключом `data/.vpnshop-secret.key`; они скрыты при загрузке страницы, а кнопка-глаз показывает выбранный секрет только после запроса администратора. Сохраните этот файл вместе с БД в закрытой резервной копии: без него зашифрованные интеграционные ключи восстановить нельзя.

## Настройки интеграций

- **Lava.top:** API URL, путь создания счёта, offer ID, API key, необязательный payment provider и отдельный ключ webhook. Настройте webhook на `https://ВАШ-ДОМЕН/webhooks/lava`, заголовок `X-Api-Key` должен совпадать с секретом webhook, событие — `payment.success`.
- **3x-ui:** базовый URL, web base path, API/login paths, API token или логин/пароль. Inbound-ы загружаются из панели и выбираются флажками; можно выбрать несколько (вплоть до десятков). В поле Email 3x-ui записывается Telegram ID согласно настройкам сервиса.
- **Happ:** базовый URL и путь подписки. Пользователь получает ссылку после подтверждённой оплаты.
- **Telegram:** токен, приветственный текст и текст оферты. Страница оферты доступна по `/offer`. При смене токена polling перезапускается.
- Также настраиваются публичный URL, дни напоминаний и часовой пояс.

Секретные поля принимают только новое значение: пустая форма сохраняет действующий ключ, а показать его повторно нельзя. При вводе нового секрета можно задать видимую метку.

## Разделы админки

- **Обзор:** текущие активные/неактивные подписки, истекающие в течение 7 дней, новые подписчики, плановые окончания срока и популярность тарифов. Показатель «Окончания срока» основан на датах окончания и не означает подтверждённую отмену.
- **Пользователи:** Telegram ID, остаток срока, цена, статус и трафик (счётчик запрашивается у 3x-ui); ручное добавление/редактирование, удаление и массовое удаление неактивных с синхронизацией панели.
- **Подписки:** несколько тарифов с ценой, сроком, лимитом трафика, числом устройств (HWID), периодом сброса трафика и отдельной видимостью в Telegram. Значение `0` отключает лимит трафика или устройств.
- **Дополнительные пакеты:** платные добавки трафика для активных тарифов; после webhook оплаты квота увеличивается без сброса уже использованного трафика.
- **История подписок:** Telegram ID, тариф, время подключения и период до.
- **Конструктор бота:** визуальное дерево кнопок для главного меню и вложенных меню; кнопка может открыть подменю, показать тарифы или перейти по HTTPS-ссылке. Порядок, текст и активность кнопок меняются в панели.
- **Система и логи:** перезапуск контейнера VPN Shop, обновление из `origin/main` с пересборкой и просмотр последних логов из панели.
- **Настройки:** внешние API и URL, бот, оферта и доступ администратора.

## Продление и данные

Повторная покупка тарифа действует как продление: если доступ ещё активен, срок добавляется к текущей дате окончания. Это **не автоматическое списание денег**: пользователь должен снова оплатить счёт. При продлении лимит трафика сбрасывается согласно выбранному тарифу.

Локально хранятся Telegram ID, текущая подписка, история подписок, тарифы, конфигурация интеграций и краткоживущая связка счёта с Telegram ID до обработки webhook. Исходный ID счёта после успешной обработки не сохраняется — остаётся односторонний хеш для защиты от повторной выдачи. Незавершённые связки очищаются через 7 дней. Приложение не запрашивает имя, username, телефон или реальный email. По настройке владельца Telegram ID также записывается в поле Email клиента 3x-ui. Внешние Telegram, Lava.top, хостинг и панель могут обрабатывать собственные технические/платёжные данные; локальное хранение не контролирует их политику.

## Перед запуском на VPS

Разместите приложение за HTTPS reverse proxy, ограничьте доступ к `/admin`, откройте webhook для Lava.top и отключите access logs reverse proxy, если не хотите сохранять IP посетителей. Ограничьте доступ к API 3x-ui по сети. Проверяйте интеграции тестовым платежом на вашей сборке 3x-ui 3.8.5: пути и ответы могут зависеть от web base path и настроек панели. Сделайте закрытую резервную копию базы и ключа шифрования.

Меню Telegram-бота настраивается в разделе «Конструктор бота»: приветствие, оферта, многоуровневые кнопки, показ сведений о подписке, выбор тарифа, покупки дополнительного трафика и HTTPS-ссылки. Навигация редактирует исходное сообщение меню. Кнопки Happ открывают HTTPS-страницу, где по нажатию ссылка копируется в буфер и запускается приложение. С одним Telegram-токеном одновременно должен работать только один экземпляр polling-бота; остановите локальный процесс, если бот уже запущен на VPS. Сетевые разрывы polling обрабатываются повторными попытками с задержкой; конфликт токена останавливает polling без необработанного исключения.

Вкладка «Система и логи» управляет контейнером через отдельный внутренний сервис `vpnshop-control`. Он не публикует порт в интернет, принимает только фиксированные команды и защищён случайным `CONTROL_TOKEN`. При первом обновлении уже установленной версии выполните из SSH `cd /opt/vpnshop`, добавьте `CONTROL_TOKEN=$(openssl rand -hex 32)` в `.env`, затем `git pull` и `docker compose up -d --build`. Новые установки создают токен автоматически.

## Установка Ubuntu 22.04 из GitHub

Укажите публичный GitHub URL в команде, домен с DNS A/AAAA-записью на VPS и внешний HTTPS-порт (обычно `443`). Для ACME проверки домена должен быть доступен входящий порт `80`; выбранный HTTPS-порт тоже должен быть открыт в firewall/security group. Установщик поставит Docker Compose, Nginx и Certbot, выпустит TLS-сертификат, запустит приложение и создаст случайные учётные данные администратора:

```bash
curl -fsSL https://raw.githubusercontent.com/matvej101269/vpnshop_panel/main/install.sh | sudo bash -s -- \\
  --domain vpn.example.com --port 443 --repo https://github.com/matvej101269/vpnshop_panel.git
```

Для нестандартного HTTPS-порта, например `8443`, панель будет доступна как `https://vpn.example.com:8443`. Данные входа печатаются в конце установки и сохраняются в `/root/vpnshop-admin.txt` с правами только для root.
